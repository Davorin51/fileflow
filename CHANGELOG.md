# Changelog

## 0.1.0 — first functional version

- Preview-first CLI and optional Qt desktop application over a shared Python core.
- Type/modified-date grouping, validated rename templates, JSON rules and read-only SHA-256 duplicates.
- Collision-aware destination preview, stale-file checks and exclusive link/unlink moves.
- SQLite operation journal, cross-process folder lock, explicit undo and interruption recovery.
- New/stable-file polling, preview-only desktop watching and opt-in CLI automatic organization.
- Synthetic demo data, actual offscreen application screenshots, tests and CI.

No standalone installer, cross-volume move, duplicate deletion or universal filesystem guarantee.
